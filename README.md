# Master_Slave_SPI
It is a synchronous communication protocol used to transfer data between master device and one or more slave devices.
Single master, Multiple slaves implies that the master selects which slave to communicate with using slave select/ chip select.
Key Signals include:   sclk (serial clock), MOSI(Master out, Slave in), MISO(Master in, Slave out), ss/cs (Slave select/ Chip select).
